# Comparing-Sap-Harvested-From-Tissues-Above-and-Below-Tap-Holes

The files in this repository go with the article 'Comparing Sap Harvested From Tissues Above and Below Tap Holes', which was published in the December 2026 issue of Maple Syrup Digest. Please navigate to the the ['Releases'](https://github.com/davidblakneymoore/Comparing-Sap-Harvested-From-Tissues-Above-and-Below-Tap-Holes/releases/tag/v1.0) portion of this repository to download the 3 .STL files corresponding to the 3 tap designs used in this study.
